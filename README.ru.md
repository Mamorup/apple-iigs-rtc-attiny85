# Замена часов Apple IIgs на ATtiny85

[English README](README.md)

Отдельный проект замены RTC/PRAM **343-0042-B** в Apple IIgs на ATtiny85.
Публикуется версия **edgefix_v3** с обработкой последовательного обмена на
ассемблере AVR для тактирования RTC примерно 2 МГц.

Автор исходного ATTinyRTC — **Phil Greenland**:
[pgreenland/attinyrtc](https://github.com/pgreenland/attinyrtc).
Его лицензия MIT и copyright сохранены. Адаптация и проверка на IIgs —
[Mamorup](https://github.com/Mamorup).

## Что входит

- Исходники C и AVR assembler.
- Готовые FLASH, EEPROM и fuse-байты версии edgefix_v3.
- Отдельные Binary-файлы для T48, инструкция по записи и таблица подключения.
- Переносимый скрипт сборки и программные тесты.
- Ссылки на документацию и описание ограничений.

На используемом IIgs наблюдался сигнал 1 Гц, а во время восстановления компьютера
получен System Good. Текущая сборка GCC 7.3.0 побайтово совпадает с сохранёнными
FLASH, EEPROM и fuse-байтами edgefix_v3. Это прототип, а не универсально
проверенная замена для всех ревизий платы и вариантов питания.

**Изменения PRAM и времени пока хранятся только в SRAM. После полного снятия
питания они теряются, и загружается исходный образ EEPROM.**
Часы работают от внутреннего RC/PLL, поэтому точность кварцевых часов не
гарантируется. Работа от батареи и длительная точность не проверены.

## Запись в T48

Файлы находятся в [releases/edgefix_v3](releases/edgefix_v3/):

| Память | Файл | Формат | Адрес |
|---|---|---|---|
| FLASH | `t48_flash_8k.bin` | Binary |0|
| EEPROM | `t48_eeprom_512.bin` | Binary |0|

Параметры: **LFUSE E1, HFUSE 5D, EFUSE FF, LOCK FF**.
Именно **5D**, а не D5. После 5D RESET превращается в PB5/выход 1SEC,
обычная запись через ISP/USBasp перестаёт работать. Для повторной записи
нужен поддерживающий HVSP программатор; чип должен быть снят с материнской платы.

Проверь запись обеих областей и fuse-байтов. Не загружай HEX в режиме Binary:
иначе в FLASH окажется текст файла, а не машинный код. EFUSE FE отличается
от FF реальным битом SELFPRGEN; это не различие зарезервированных битов.

[Полная инструкция T48](docs/PROGRAMMING.md) · [Куда паять](hardware/WIRING.md)

## Сборка

```sh
python tools/build.py
python tools/verify_images.py build
python tests/run_tests.py
```

Нужны Python 3, AVR GCC/binutils/avr-libc; для тестов протокола — обычный GCC.
AVR-компилятор ищется через PATH или параметр `--toolchain`.
Скрипты ничего не прошивают автоматически. Файлы старого загрузчика Digispark,
чужие PDF и большие захваты анализатора в репозиторий не включены.
